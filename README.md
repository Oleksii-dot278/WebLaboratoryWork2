## 1. Для чого використовується CSS?
### CSS використовується для візуального оформлення та стилізації веб-сторінок: задання кольорів, шрифтів, розмірів, відступів та розташування елементів.

## 2. Які способи підключення CSS ви знаєте?
### Існує три основні способи:
### Зовнішній (External): через тег <link> до окремого файлу .css (найкраща практика).
### Внутрішній (Internal): за допомогою тега <style> у блоці <head> HTML-документа.
### Вбудований (Inline): через атрибут style безпосередньо в HTML-тегу.

## 3. Чим відрізняється селектор елемента від селектора класу?
### Селектор елемента застосовує стилі до всіх тегів цього типу на сторінці. Селектор класу застосовує стилі лише до тих елементів, яким задано відповідний атрибут class. Клас можна застосовувати до різних типів тегів багаторазово.

## 4. Для чого використовується id?
### Атрибут id використовується для унікальної ідентифікації одного конкретного елемента на сторінці. Значення id має бути унікальним у межах всього HTML-документа.

## 5. Що робить універсальний селектор *?
### Він вибирає абсолютно всі елементи на веб-сторінці. Часто використовується на початку файлу стилів для скидання базових налаштувань браузера.

## 6. Для чого потрібен селектор атрибута?
### Він дозволяє вибирати елементи на основі наявності або конкретного значення певного HTML-атрибута.

## 7. Що таке каскад CSS?
### Це алгоритм браузера, який визначає, яке саме правило застосувати до елемента, якщо на нього діє кілька різних стилів. Каскад враховує джерело стилів, специфічність селекторів та порядок їх оголошення в коді.

## 8. Що таке specificity?
### Це вага селектора, яка визначає пріоритет застосування CSS-правил у разі конфлікту. Чим точніший селектор, тим вища його вага. Пріоритет від найменшого до найбільшого: тег < клас / псевдоклас < id < inline-стилі < !important.

## 9. Який селектор переможе: p, .warning чи #warning?
### Переможе #warning, оскільки селектор за ідентифікатором (id) має найвищу специфічність серед перелічених.

## 10. Чому CSS-правило може бути перекресленим у DevTools?
### Це означає, що правило не застосовується. Основні причини: воно перевизначено іншим правилом з вищою специфічністю, скасовано правилом з !important, або правило містить синтаксичну помилку.

## 11. Чим відрізняються margin і padding?
### margin - це зовнішній відступ; відстань від межі елемента до сусідніх елементів.
### padding - це внутрішній відступ; відстань від межі елемента до його внутрішнього вмісту.

## 12. Що входить до Box Model?
### Будь-який HTML-елемент розглядається як прямокутний блок, що складається з 4 областей:
### Content 
### Padding 
### Border
### Margin

## 13. Чим відрізняються block, inline-block та inline?
### block: займають всю доступну ширину батьківського елемента, починаються з нового рядка. Їм можна задати width, height, margin і padding.
### inline: займають лише стільки ширини, скільки потрібно для їхнього вмісту, не переносяться на новий рядок. Їм не можна задати width та height, а вертикальні margin і padding не відштовхують сусідні елементи.
### inline-block: поєднують обидві властивості. Вони розташовуються в рядок, але їм можна задавати ширину, висоту та всі відступи.

## 14. Для чого потрібен box-sizing: border-box?
### За замовчуванням ширина/висота елемента включають лише контент. Якщо додати padding чи border, загальний розмір блоку збільшиться. box-sizing: border-box змушує браузер включати padding та border у задані значення width та height, що робить розміри елементів передбачуваними та спрощує верстку.

## 15. Чому зміна CSS-правила іноді не змінює вигляд елемента?
### Причини можуть включати:
### Правило перебивається іншим з вищою специфічністю.
### Стилі закешувалися в браузері.
### Неправильно підключений CSS-файл або допущена синтаксична помилка вище по коду.
### Ви намагаєтеся застосувати властивості до елемента, які він не підтримує.
